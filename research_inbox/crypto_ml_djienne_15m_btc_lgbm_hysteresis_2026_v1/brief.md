# djienne: pooled BTC+ETH LightGBM training, single-BTC 15m quantile hysteresis

**THESIS_CAPTURED · SOURCE_CAPTURE_ONLY.** Primary [author repository](https://github.com/djienne/ML_Trading_Strategy_Crypto_BTC_LightGBM_Jansen), [STRATEGY.md](https://github.com/djienne/ML_Trading_Strategy_Crypto_BTC_LightGBM_Jansen/blob/main/STRATEGY.md), and [EXPECTED_PERFORMANCE.md](https://github.com/djienne/ML_Trading_Strategy_Crypto_BTC_LightGBM_Jansen/blob/main/EXPECTED_PERFORMANCE.md), reviewed 2026-10-18; no source code or strategy execution performed.

The author trains a LightGBM return regressor on BTC+ETH 15m candles for next-bar simple open-to-close return, **but trades BTC long-only**. Predictions are discretized into rolling quantiles: enter at top bin 100, exit below 90, reset flat at month end, block the first hour of each month. Feature families include recent simple returns and several indicators/alpha factors, with a fixed 480-bar trailing rank to avoid prior expanding-window live/replay mismatch. The current described contract uses monthly refits on a 12-month window; the author publishes a hashed model-owned configuration and measured (not independently audited) dry-run parity.

**Source-reported, NOT verified ATS outcomes:** net +277.4% and Sharpe 1.33 through 2026-07-04 with fees 0.03% per transition; at 0.05% source reports Sharpe 0.83. These are tied to the **July artifact**, not the later 2026-08-13 deployed artifact. Author discloses optimizer winner's curse, earlier feature-parity leak fixed in June, and unmodeled live slippage/fills/stops/financing. Consequently this is not proof of profitable execution.

**Distinctive ML question:** Does learned 15m return-tail prediction with regime-relative rolling quantiles add anything over simple causal trailing momentum under identical hysteresis? This differs from previously captured *cross-sectional multi-coin rankers* because model training is pooled but inference and state are single-symbol. The stateful long/flat program is **BLOCKED_PROTOCOL** for the current ATS synchronous long/short rank factory. Any crypto basket adaptation must be separately labeled. No funding-based signal is proposed.
