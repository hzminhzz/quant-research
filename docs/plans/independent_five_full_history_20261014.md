# Independent five full-history extension — frozen exploratory test

Date: 2026-10-14. State: PRE-RESULT PLAN.
No change to Shannon or its twenty sleeves.

## Question

Do the five independent strategies that had positive 2020–2022 Sharpe
still work over the rest of eligible canonical local ML4T market history?
What do their historical pre-2020 and post-2022 results show?

## Frozen selection

Select ONLY the five prior positive-Sharpe cases, with zero parameter search:
1. pivot-breakout-btc
2. donchian-btc
3. three-red-spy
4. slope-hook
5. rsi-30-50

Keep the exact source/feature/engine strategy classes, cost and sizing
assumptions from the recorded 2020–2022 experimental run.
Use native ml4t-engineer features and ml4t-backtest Engine.

## Data

BTC: canonical `crypto_futures_minute_BTCUSDT_PERP`, earliest locally
available September 2019, aggregated into full UTC calendar days.
ES: canonical `index_minute_ES`, earliest locally available 2011,
aggregated into 17:00 New York session-ending daily bars. ES is an
index/CFD-price proxy for SPY, not SPY ETF.

Follow the loader's fixed minimum session count and validation.
**Do not scan any market data on or after 2026-10-12T00:00:00Z.**
This preserves the repository's 2026-10-12+ protected data boundary.
Only available *complete* days/sessions up to that cutoff are eligible.
Each backtest starts after available native feature warmup.

## Evaluation and anti-overfitting

Run the FIVE fixed cases once over entire eligible native data.
No optimization, cost tuning, parameter search, or survivor re-ranking.
Report whole-history native metrics, a chronological year-by-year ledger,
and 2020–2022 versus 2023–2025 versus 2026-YTD segments, including
negative/inconclusive cases.

2020–2022 was already reviewed and used for selecting these five.
2023+ has been previously observed in related research and is not
a new untouched final test. Label all 2023+ results exploratory historical
extension. A long dataset does not create independent holdout evidence.
Do not declare promotion or live approval.

## Quality gates

- Input source identity / first / last / monthly partition count documented
- Pre-2026-10-12 raw cutoff enforced before aggregation and features
- Native features untouched and source-specific
- Next-bar native execution, cash/fills/trades/equity owned by ML4T
- Source price, signal, equity, fill, trade and native summary persisted
- Reconcile counts, artifact hashes, equity final value and zero rejects
- Tests include truncation/prefix check and holdout boundary
- Test shortfall, source mismatch, or coverage gaps reported honestly

## Pre-declared additional cost stress (after baseline observation)

This is a separate exploratory follow-up trial, NOT a preregistered
confirmatory holdout. For all five cases (without survivor re-selection),
run native Engine at 2x and 3x both commission and slippage versus
the original 1x fixed-cost assumption. Do not change signals,
data or sizing. Preserve all trial outcomes. A weak result is not
a rationale to reduce assumed execution costs.

## Open limitations

BTC funding, leverage financing and ES/ETF corporate action/financing
differences remain unmodeled. Fixed bps are research assumptions.
Pivot stop order mechanics and protective stop activation require
additional execution audit. Sharpe from engine is reported exactly
as generated by its installed version; crypto annualization convention
must be confirmed before comparative claim.
