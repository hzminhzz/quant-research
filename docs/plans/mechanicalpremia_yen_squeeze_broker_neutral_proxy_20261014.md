This is intentionally NOT historical USDJPY conversion or a precise USD account; report sensitivity and limitation. Do not arbitrage price source, do not invent actual FX broker contract. 1 unit = 1 base-currency unit, 1% of native portfolio account balance risk per pending entry at initial 2x ATR stop; native leverage modeled with 5% initial margin (20x max) but risk 1% each entry, no min broker lot, fractional 1 unit. 24/5 OTC FX, no synthetic weekend bars. Use native BacktestConfig SlippageType.FIXED and test sign, multiple fills. These costs incorporate spread, commission, small slippage as *one all-in fixed proxy*; avoid double counting. Financing/swap left unmodeled with explicit warning, not declared realistic full broker cost. Quote spread proxy half the per-round-trip allowance per side and signal bid/ask approximated. Cash/equity and portfolio PnL MUST come solely from native Engine, with no custom simulation or equity calculators. ## Source clock/conditional native orders
At UTC hour boundary using only completed H1 data, submit BuyStop at channel high if above estimated ask and SellStop at channel low if below bid; source can submit BOTH orders, no OCO. Pending valid for 1h from source timer decision; expire using native cancel. Initial stop 2x completed-H1 ATR from pending entry. Trailing once per minute behind *current side-appropriate bid/ask* by last completed H1 2x ATR, ratchet only, 2-point minimum move. Use native ml4t.backtest.Engine/Broker STOP orders, native fills, native accounting. Before performance, prove stop entry protection semantics: library might permit immediate linked protective fills or built-in risk rules. If it does not, declare explicitly a fixed broker-neutral approximation: one-bar (1m) protection activation delay with pessimistic gap fill and a stress/failure count of unprotected entry bars. The proxy variant is permitted with this predeclared deviation, not source exact. Never substitute a custom fill simulator, numpy position-return loop, or custom cash/portfolio math. Do not treat opposite entry as protective; preserve short/long netting caveat. Cancel/avoid orders at ambiguous dual-stop same minute and count occurrences conservatively; explicit deterministic native order sequencing.
