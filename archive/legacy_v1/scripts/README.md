# Legacy research command archive

These scripts are kept verbatim for historical reproducibility and Git history. New quantitative research must use `scripts/quant.py` or `src.workbench.Workbench`. Archived entry points are not production or factory execution paths. Some depend on still-active legacy compatibility modules, which remain in their original locations until parity-tested migration. Do not alter historical trial results or sources to make an archived script pass.

Only the scripts verified to have no active source/test imports were moved here. See `docs/architecture/dual_mode_20261015/archive_inventory.md` for retained imports, frozen paths, and the audit snapshot.
